# Python Student Performance Analysis

## 📌 Project Overview
Exploratory data analysis (EDA) and Python scripts analyzing student performance, demographics, and academic trends to uncover insights into student success factors.

## 🛠️ Key Libraries & Techniques
* **Pandas & NumPy**: Data cleaning, manipulation, and statistical aggregation
* **Matplotlib & Seaborn**: Data visualization and trend discovery
* **Exploratory Data Analysis (EDA)**: Investigating demographic correlations and performance distributions
